
# Log-Based Intrusion Detection & Automated Response System

## Project Description
A Python-based system that monitors login activity from log files, detects possible attacks (like brute-force), and simulates automated responses.

## Features
- Simulated log generation
- Rule-based threat detection
- Risk classification (Low/Medium/High)
- Automated response simulation
- Alert reporting

## How to Run
1. Run `python main.py`
2. Check `reports/alerts.txt` for results
